# 판치기 개인정보처리방침

- 공개 경로: `https://baekwangho.github.io/panchigi/privacy/`
- 계정·데이터 삭제 안내: `https://baekwangho.github.io/panchigi/privacy/#delete`
- 한국어 본문: [policy-ko.md](policy-ko.md), 최종 수정일 2026-11-06. 영어판은 이번 범위 밖입니다.
- `index.html`은 같은 본문을 담은 정적 페이지이며 `style.css`를 사용합니다. 본문을 고칠 때 두 파일을 함께 갱신합니다.
- 기존 `panchigi/join/`의 색상과 로컬 제목 서체를 재사용합니다. 본문은 시스템 서체입니다. JavaScript, 외부 폰트·이미지 요청, 추적 도구, 입력 폼은 없습니다.
- 검증: 9개 절과 `#delete` anchor, Markdown/HTML 본문 일치, 로컬 리소스, 로컬 HTTP 200, 글자 대비를 확인했습니다. 실제 브라우저 렌더링·휴대폰 앱 링크 실행은 아직 확인하지 않았습니다.

이 PR은 조정자의 문구 검토용이며 자동 병합하지 않습니다. main 병합 후 Pages의 공개 URL과 `#delete`를 먼저 확인하고, 클라이언트의 링크 변경을 반영해야 합니다. PR 생성만으로 기존 사이트·설치 앱·스토어 등록 URL은 바뀌지 않습니다.

기존 ChatGPT Sites 주소를 직접 편집하거나 리디렉션할 수 없습니다. Google Play(개인정보처리방침·데이터 삭제 URL), App Store Connect, AdMob/UMP 동의 메시지, Google OAuth 동의 화면에 남은 주소는 소유자가 확인하고 변경해야 합니다. 해당 콘솔의 현재 값은 이번 PR에서 검증하지 않았습니다.
